# 🏋️ FitGlow - Bootstrap 5 Fitness Website

Modern fitness platform for women built with Bootstrap 5.

## 📦 What's Inside

**6 Pages:**

- Home
- Classes
- Trainers
- Pricing
- Blog
- Contact

**Bootstrap Components:**

- Navbar, Cards, Modals, Carousel, Forms, Offcanvas, Badges, Buttons

**Features:**

- Pink/rose theme
- Fully responsive
- Form validation
- Interactive filters
- Smooth animations

## 🚀 Quick Start

1. Extract the ZIP
2. Open `index.html` in browser
3. Done!
