# 🏋️ FitGlow - Fitness & Wellness Platform

Modern, responsive fitness website built with **Bootstrap 5** for women's wellness and fitness community.

## 🔧 Customization

### Change Colors
Edit `css/style.css`:
```css
:root {
    --primary: #your-color;
    --primary-dark: #your-dark-color;
}
```

### Add New Page
1. Copy any page from `/pages`
2. Update content
3. Add link to navbar

### Modify Content
- Images: Replace `src` URLs
- Text: Edit HTML directly
- Styles: Modify `style.css`
